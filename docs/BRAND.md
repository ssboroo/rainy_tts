# RAINY Voice Studio — Signal identity

The standalone logo contains exactly three angular signal bars, descending left to right. No letter or enclosure is part of the mark.

Primary palette: Electric lime #B7FF4A, near black #080A0D, soft white #F3F1E9. Cyan #78E8FF is a secondary accent.

Default theme is dark; light mode remains available. Buttons use lime with near-black text. Mobile navigation uses the existing accessible drawer and dock.

Use brand-mark.svg for the logo, brand-mark-mono.svg for a single-color treatment, brand-wordmark.svg for a dark-background lockup, and brand-social.svg for a social card. The SVG geometry is crisp and has no raster glow or background.
