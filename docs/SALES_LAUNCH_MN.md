# RAINY Voice — борлуулалтын нээлт

2026-10-09. Кодын бэлтгэл нь live төлбөр амжилттай гэсэн баталгаа биш.

## Хэрэглэгчийн урсгал

1. Хоолойн сангийн дээж сонсох, хэрэглээний жишээ текст турших.
2. Үнэгүй бүртгэл үүсгэх. Үүсгэлтийн үнэгүй кредит default 0.
3. Сарын багцын үнэ, кредит, зөвхөн TTS ашиглах үеийн ойролцоо тэмдэгтийн хэмжээг харах.
4. Hosted checkout руу шилжих. Төлбөр зөвхөн серверийн баталгаажуулалтаар кредит олгоно.
5. Төлбөрийн цонх хаагдсан ч Багц хэсгийн өөрийн захиалгаас үргэлжлүүлж, төлөв шалгах. Давтан төлөхөөс өмнө өмнөх захиалгаа шалгана.
6. Текстээ оруулж quote шалгах, үүсгэлт хийх, үр дүнгээ татах.
7. Багц хэсгээс зөвлөгөө/тусламж хүсэх. Хүсэлт, админы хариу дансанд хадгалагдана; email notification хараахан нэмээгүй. Админ тогтмол хүсэлт шалгана.

## Тохиргооны үлдсэн ажил

Production `rainy_tts` service-ийн Railway Variables-д эзэмшигч нууц утгаа өөрөө оруулна:

- `WIRE_MN_API_KEY`: идэвхтэй live түлхүүр.
- `WIRE_MN_WEBHOOK_SECRET`: энэ endpoint-ийн signing secret.
- `WIRE_MN_ALLOWED_OPERATORS`: live операторын ID эсвэл хоосон; sandbox биш.
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_FROM`, `SMTP_TLS`; sender шаардвал `SMTP_USER`, `SMTP_PASSWORD`.

Wire dashboard-д endpoint:
`https://voice.rainy.studio/api/billing/wire/webhook`

Эдгээрийг GitHub, support хүсэлт эсвэл чатад ил тавихгүй. Credentials байгаа нь зөв ажиллахыг батлахгүй.

## Live acceptance

- Нэг бодит бага дүнтэй төлбөрөөр яг MNT дүн, нэг удаагийн кредит, багцын хугацааг шалгах.
- Ижил signed event давтан ирэхэд давхар кредитгүйг шалгах.
- Checkout-оос буцаж ирэх, цонх хаах, дараа нэвтрэх үед захиалгаа олох.
- Нууц үг сэргээх email ирэх, token нэг удаа ашиглагдах.
- Богино Монгол TTS үүсгэж сонсох, татах; төлбөр/quote/суутгал тулгах.
- STT, dubbing, clone зэрэг хэрэгслийг эрх ба бодит чанарыг нь тус бүр шалгасны дараа сурталчлах.
- DB + media-г тусдаа хадгалалт руу backup хийж, тусгаарласан restore турших.

## Өртөг

Одоогийн pricing minimum markup нь 2.2× modeled total cost. 2026-10-06 audit-ийн 3× тэмдэглэл нь өмнөх хувилбарын мэдээлэл. Үнэ нь бодит ашиг батлахгүй; provider invoice, хостинг, шимтгэл, татвар, дэмжлэгийн зардлыг тулгана. Шинэчилсэн provider snapshot/capacity хамгаалалт checkout-ийг хааж эсвэл шинэ захиалгын үнийг өөрчилж болно. Өмнөх төлбөрийн захиалгын quote хадгалагдана.
